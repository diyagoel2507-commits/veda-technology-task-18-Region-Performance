
#  Region Performance Analysis

##  Project Overview

This project focuses on analyzing regional sales and profit performance using Microsoft Excel. It was completed as part of the VEDA Technology Level 1 – Day 18 task.

The analysis uses a Pivot Table and charts to compare sales and profit across different regions and identify regional performance patterns.

##  Objectives

- Analyze total sales by region.
- Analyze total profit by region.
- Compare regional sales and profit performance.
- Rank regions based on sales and profit.
- Create a visual representation using a bar chart.
- Develop practical Excel data analysis skills.

##  Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Bar Charts
- Data Analysis
- Data Formatting

##  Dataset

The analysis was performed using a Sample Superstore dataset containing sales, profit, and regional information.

### Key Columns Used

- Region
- Sales
- Profit

##  Analysis Summary

| Region | Total Sales | Total Profit |
|---|---:|---:|
| East | $25,149.15 | $2,369.52 |
| West | $23,806.77 | $2,456.81 |
| South | $23,425.27 | $2,128.80 |
| Central | $22,791.90 | $1,614.14 |
| **Grand Total** | **$95,173.09** | **$8,569.27** |

##  Key Insights

1. East recorded the highest total sales among the four regions.
2. West recorded the highest total profit.
3. Central recorded the lowest total sales and total profit in this dataset.
4. Sales and profit rankings differ, highlighting the value of analyzing both metrics.
5. A regional bar chart was created to compare sales and profit visually.
